🌐 Personal Portfolio Website

A responsive, modern, and fully interactive portfolio website built with React.js, designed to showcase my skills, projects, and experience as a software developer. 
✨ Features

🧭 Single-Page Application (SPA): Smooth navigation and routing with react-router-dom

🎨 Modern UI/UX: Clean, responsive design with Sass and animate.css for stylish animations

⚡ Dynamic Components: Modular and reusable components for scalability and maintainability

📬 Contact Form Integration: Functional contact form powered by EmailJS

🧪 Testing: Implemented testing with @testing-library/react to ensure stability and reliability

🚀 Optimized for Deployment: Configured build scripts and production optimizations for fast loading and seamless deployment

🛠️ Tech Stack

Frontend: React.js, JavaScript (ES6+), HTML5, CSS3, Sass

Libraries & Tools: GSAP, Animate.css, React Router, EmailJS

Build & Testing: Create React App, npm scripts, @testing-library/react
